# Linux TAIL Command Assignment

## Aim

To display the end of a file or the last few lines of output from a command using the Linux `tail` command.

---

## Objectives

Students should learn:

- How to create a file with multiple lines
- How to display the last lines of a file
- How to display a specific number of lines
- How to use `tail` with the pipe (`|`) operator
